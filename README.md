# LifeOS

Personal Life Operating System.

## Vision

LifeOS transforme la vraie vie en système de progression adaptatif : objectifs, habitudes, tâches et contraintes réelles de l'utilisateur.

## Stack actuelle

- Next.js / React
- TypeScript
- Node.js tests
- GitHub Actions (CI)

## Structure

```text
app/        # interface Next.js
src/        # logique métier TypeScript
scripts/    # scripts de développement et build
test/       # tests automatisés
docs/       # documentation technique
```

## Commandes

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## État du projet

Le dépôt contient actuellement une base Next.js et un moteur TypeScript historique. La prochaine étape consiste à consolider l'architecture autour de l'application Next.js tout en conservant les règles métier testées.
