# G-FONDATION

**G-Fondation** est le nom de la nouvelle fondation du projet LifeOS.

## Vision

Transformer la vraie vie en système de progression, en adaptant les objectifs aux contraintes réelles de l’utilisateur : travail, famille, sommeil, énergie et temps disponible.

## Architecture actuelle

Ce repository est **l’unique repository du projet**.

- `app/` — interface Next.js
- `src/` — logique métier existante
- `components/` — composants UI
- `public/` — ressources statiques
- `scripts/` — outils de développement et build
- `test/` — tests
- `docs/` — documentation

### Règle d’organisation

Une seule application, un seul repository, une seule branche principale : `main`.

Les anciennes branches et PR servent uniquement à conserver l’historique du développement. Elles ne représentent pas plusieurs projets.

## Stack

Next.js · React · TypeScript · Node.js

## Statut

Fondation technique en cours de consolidation avant l’ajout des fonctionnalités produit.
